# Jeevan Raksha Safe

Build a full-stack mobile-first web application called 'Jeevan Raksha' focused on Women Safety and Emergency Response. Features: 1) One-tap SOS button. 2) Triple volume button press emergency trigger. 3) Live GPS location sharing with family, police, and emergency contacts. 4) Real-time location tracking dashboard. 5) Emergency siren and flashlight activation. 6) Voice activation using keywords like 'Help Me'. 7) Automatic emergency call if user does not respond within 15 seconds. 8) Audio and video recording during emergencies with secure cloud storage. 9) Nearby police station and hospital locator using maps. 10) Trusted contacts management. 11) Emergency alerts via SMS, email, and push notifications. 12) Incident history and evidence storage. 13) AI-based risk detection from loud distress sounds. 14) Fake call feature for safety. 15) Safe route navigation showing well-lit routes. User roles: User, Admin, Police, Hospital. Database: users, emergency_contacts, incidents, location_logs, alerts, police_stations, hospitals. Design: modern, professional, red and blue safety theme, clean dashboard, mobile-first UI, Google Maps integration, authentication, real-time notifications, responsive design. Include landing page, registration, login, dashboard, emergency screen, admin panel, police panel, and hospital panel.
